# Component sources and adaptations

The site uses a consistent Digiinn360 visual system rather than unmodified demos.

- **FAQ and Accordion** — actual source adapted from Kevin Girelli's Corsair UI, discovered through https://21st.dev/@kevingirelli/components/faq. Source: https://github.com/KevinGirelli/corsair-ui/tree/main/registry/default. MIT license, copyright (c) 2026 Kevin Girelli. Imports, content and presentation adapted locally; accessible Radix accordion retained.
- **Tubelight navigation** — local implementation of the active-pill/light interaction shown at https://21st.dev/@ayushmxxn/components/tubelight-navbar by Ayushmaan Singh. Added section tracking, sticky header and responsive drawer. Component source was account-gated; this is a pattern adaptation, not a copied source file.
- **Security bento** — local implementation using composition references from https://21st.dev/@manuarora700/components/bento-grid by Manu Arora. Original SVG/CSS security illustrations and brand content.
- **Spotlight cards** — local pointer-light implementation inspired by https://21st.dev/@jahed/components/spotlight-card by Hossain Jahed. No gated source copied.
- **Team panels** — local accessible expansion pattern inspired by the Interactive Image Accordion collection at https://21st.dev/community/components. Uses initials rather than stock photos misrepresenting real staff.
- Original supplied hero, carousel and spatial showcase references remain adapted for Digiinn360.
