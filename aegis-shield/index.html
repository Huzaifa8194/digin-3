How it works

One path carries every event to a decision.

  1. CollectThe endpoint sensor records process, network, registry and file activity.
  2. DetectTuned Sigma rules, maintained as code, tag each hit with its technique.
  3. HuntThe persistence collector reads every autostart on every host.
  4. RespondThe response agent acts back on the endpoint, with a full trail.

Automated response

Confirmed, then contained.

  1. 01Stop the process

    A malicious program is terminated the moment a rule confirms it.

  2. 02Quarantine the file

    The offending file is moved out of reach so it cannot run again.

  3. 03Isolate the host

    A compromised machine is cut off from the network to stop the spread.

Governed by design: every action is scoped, logged and reversible where it can be, and role-based access decides who may trigger what.
