# /design3: "DigiInn360, the device" (product launch, multi-page)

Built with `/awwwards`. Award product sites build everything around one hero object; this treats
DigiInn360 itself as that object. It says plainly that the device is imaginary.

## Concepts

| | Idea | O / F / Fe / P |
|---|---|---|
| A. The device | A glossy security core made of five coloured modules (one per product) on a services base under a 360° ring light, sold like a flagship launch | 5 / 4 / 4 / 2 |
| B. Five editions | Each product as a boxed edition | 3 / 3 / 4 / 3 |
| C. Collectible tokens | Products as 3D tokens | 3 / 2 / 4 / 3 |

```
Idea:        DigiInn360, imagined as one product: five modules, one core, every angle.
Metaphor:    a hardware launch (hero render, exploded view, colourways, specs, "get it").
Signature:   one Three.js renderer drawing many views into the page: hero, exploded stack,
             colour picker, five service objects, a drag-to-turn 360° turntable, a mini-device burst.
Emotion:     joy and confidence: saturated fields, glossy objects, big type.
Motion verb: snap. Modules slide out and click back; fields wipe from one colour to the next.
Screenshot:  the exploded stack on cream, five coloured layers floating apart with their names.
```

## System

- Field colours by section: hero red `#e8102a`, cream `#f3efe6`, product colours on pick, ink black
  `#0c0c0f`, violet `#5b2bff` (360°), lime `#c8f23a` (get it).
- Module colours: ShadowAD lime `#b6f23a`, SysBastion cobalt `#3d6bff`, AEGIS-SHIELD orange `#ff7a1a`,
  Mobile Pentest pink `#ff5fa2`, DarkIntel360 violet `#8b5cff`; base graphite; cap white with red ring.
- Type: Manrope 800 at display sizes, JetBrains Mono for spec labels.
- Pages: `/design3/` (product page) and `/design3/specs/` (tech specs).
- Content: everything from the current landing page (services, products, training, contact, FAQ).
