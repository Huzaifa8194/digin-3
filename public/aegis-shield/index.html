01 / Detection & response

Follow the evidence.

AEGIS-SHIELD combines endpoint visibility with behavior-based detections and response actions.

01 / Visibility

Endpoint activity

Capture process activity, network connections, file changes and driver loads in real time.

02 / Behavior

Threat detection

Identify behaviors such as credential theft and defense tampering, mapped to MITRE ATT&CK techniques.

03 / Persistence

Startup and autorun hunting

Review autorun and startup entries in a ranked worklist that separates trusted and untrusted activity.

04 / Change

New activity alerts

Flag activity that departs from the estate baseline, such as an unfamiliar program configured to run at boot.

05 / Containment

Endpoint response

Stop a malicious process, quarantine a file, remove persistence or isolate the affected host.

06 / Monitoring

Alerting and health

Deliver high-value detections to analysts and monitor platform health for coverage gaps.

02 / Operations

From endpoint to analyst.

  1. Protected endpointsAgents record activity and carry out response actions.
  2. Collect and detectNormalize events and check them against curated detections.
  3. Hunt and alertPrioritize persistence findings and alerts on new activity.
  4. Analyst consoleTriage findings, review ATT&CK context and initiate response.

Response travels back to the endpoint. Stop a process, quarantine a file, remove persistence or isolate the host.
